# shared

Test data that both halves of the system must agree on. The SDK (TypeScript) and the server (Python) each assign users to variants, and their answers must match byte for byte, so both test suites check them against the same vectors.

Read first:
- [hash_test_vectors.json](hash_test_vectors.json): 57 hash, 45 assignment, and 27 flag vectors, generated by [server/scripts/generate_hash_vectors.py](../server/scripts/generate_hash_vectors.py) from [server/src/abtest/assignment.py](../server/src/abtest/assignment.py)
